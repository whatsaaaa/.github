# Security policy

## Reporting a vulnerability

Report it privately on GitHub: open the **Security** tab of the repository and choose **Report a vulnerability**. Please do not open a public issue.

You will get a first answer within three working days. The fix ships as a patch release, and a GitHub security advisory is published together with it.

## Supported versions

| Version | Supported |
| --- | --- |
| The latest release line | Yes |
| Older releases | No |

A repository without releases is supported on its default branch.
